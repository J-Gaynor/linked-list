**Linked List Structure**
Linked lists are linear collections of data elements called nodes that “point” to the next node by means of a pointer. Each node holds a single element of data and a link or pointer to the next node in the list. The head is the first node, and the tail is the last node.

[ NODE(head) ] -> [ NODE ] -> [ NODE(tail) ] -> null
